# Alignment — Yuva Yodha Challenge 02 (Smart Buildings)

Schneider Electric · Yuva Yodha Energy Tech Hackathon

## Challenge goals mapped

| Challenge intent | Platform response |
|------------------|-------------------|
| Cut energy waste | Occupancy-driven HVAC/lighting setback; fault detection |
| Improve occupant experience | Comfort retained where occupied; IAQ indicators; tenant feedback |
| Data-driven management | Command center, KPIs, explainable decisions, manager overrides |
| Grid integration | Solar self-consumption, demand-response, outage load tiers |

## Standards used as design references
- ECBC commercial energy performance intensity baselines
- Adaptive thermal comfort practice for setback vs occupied zones
- Measurable outcomes: kWh saved, peak reduction, ₹ impact, CO₂ avoided

This repository is built specifically for Challenge 02 Smart Buildings evaluation and demonstration.
